# Zapret Control 1.5.0

Windows 10/11 x64: локальный интерфейс для системных DPI-правил HTTP/TLS/QUIC, YouTube, ИИ-сервисов и Discord RTC. Это не VPN: внешний IP и страна не меняются.

## Discord: голос и чужой эфир

- RTP/RTCP в обоих направлениях не отправляются в userspace. Перехватываются только необходимые служебные сигнатуры и QUIC Initial.
- Режим RTC задаёт UDP и TLS-сигнализацию `discord.media`, а не только один UDP-шаблон.
- Кнопка «Совместимый режим эфира» применяет совместимый UDP / чистый TLS. После применения переподключитесь к каналу или просмотру.
- Для ручной проверки есть прямое медиа без изменения RTC / media TLS; этот режим не включается автоматическим подбором.
- Новые `NO_ROUTE`, включая ошибку с последующим отключением в одном чтении журнала, и наблюдаемое зависание попытки на 25 секунд могут запустить ограниченный подбор: максимум две альтернативы, затем откат.
- Просмотр не считается рабочим по `RTC_CONNECTED` или HTTP 200. Отдельная диагностика показывает свежие локальные счётчики пакетов и декодированных кадров.

Автоподбор читает обычный Discord для ПК. В браузере режим выбирается вручную. Применение перезапускает наш движок и может прервать текущие соединения. Голос и эфир в реальном аккаунте нужно проверять отдельно: автоматические тесты не гарантируют работу всех регионов и трансляций.

## Быстрый запуск исходников

Нужны Windows x64 и .NET SDK 9.x. Сначала импортируйте совместимый локальный Engine из ранее проверенного пакета:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Import-Engine.ps1 -EngineDirectory 'C:\path\to\ZapretControl\Engine'
dotnet build .\ZapretCore\ZapretCore.csproj -c Release
dotnet test .\tests\ZapretCore.Tests\ZapretCore.Tests.csproj -c Release
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Build-CoreRelease.ps1 -Version 1.5.0
```

Готовый локальный пакет: `artifacts/ZapretControl-1.5.0`, ZIP рядом. Запуск рабочего обхода требует прав администратора. Архив нужно распаковать полностью; папку Engine нельзя терять или заменять файлами другого выпуска.

Нативные двоичные зависимости и Lua стороннего движка не хранятся в Git. Их точные хеши находятся в `runtime-engine.lock.json`; импорт не запускает их. Публичный выпуск нативного комплекта требует отдельной проверки его происхождения и условий распространения. Этот репозиторий не содержит установщика, который скачивает неизвестные EXE.

## Проверки без нативного комплекта

```powershell
dotnet build .\ZapretCore\ZapretCore.csproj -c Release -p:CoreIncludeEngine=false
dotnet test .\tests\ZapretCore.Tests\ZapretCore.Tests.csproj -c Release --filter "Category!=NativeEngine"
```

Это компиляция кода и управляемые / loopback-тесты, не рабочий DPI-пакет. CI выполняет именно эти проверки. Полный локальный набор дополнительно проверяет WinDivert и Lua из импортированного Engine.

## Что включено

`ZapretCore/` — приложение и собственные ресурсы; `tests/` — регрессионные и сетевые проверки; `Scripts/` — сборка, импорт зависимостей и контроль публикации. Подробная русская инструкция: [ZAPRET_CONTROL_1_5_0_RU.txt](ZAPRET_CONTROL_1_5_0_RU.txt).

Старые мобильные приложения, админ-панели, FTP/VDS-конфигурации, VPN/VLESS-компоненты старого проекта, пользовательские журналы и сборочный мусор не включены. Первоначальный рабочий каталог при выделении проекта не удалялся.

## Безопасность

Никогда не коммитьте PAT, пароли, `.env`, настройки аккаунтов и журналы Discord. После раскрытия токена отзовите его; для GitHub используйте `gh auth login` с входом через браузер. Перед push выполните `Scripts/Test-PublishSafety.ps1`: он печатает имена проблемных файлов, но не найденные секреты.

Сертификаты TLS проверяются штатно. Программа не отключает брандмауэр / антивирус, не меняет шифрование Discord, не входит в аккаунт и не изменяет настройки чужих туннелей. Списки доменов / адресов обновляются как проверенные данные, не как исполняемый код.
